## Run the notebook

1. Open the **Equity_Tail_Risk** folder in VS Code.
2. Open `Equity_Tail_Risk.ipynb` and select a Python/Jupyter kernel.
3. Select **Run All** (or **Restart Kernel and Run All**).

The notebook reads both CSV files from `Data/Raw/` and saves generated figures and tables to `outputs/`. No data downloads or path changes are necessary. The first code cell installs missing Python packages if pip and internet access are available; an installed Python/Jupyter kernel is required to run any notebook.
